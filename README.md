# Kolaya Design - Brand & Web Development

![Kolaya Design Banner](https://img.shields.io/badge/Kolaya-Design-blueviolet) ![React](https://img.shields.io/badge/React-18.2-blue) ![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue) ![Vite](https://img.shields.io/badge/Vite-5.0-purple)

A modern brand identity and web design agency website built with React, TypeScript, and Vite. Kolaya Design specializes in creating cohesive brand identities and intuitive UI/UX designs that transform digital interactions into engaging experiences.

## ✨ Features

- **Modern Stack**: Built with React 18, TypeScript, and Vite for optimal performance
- **Responsive Design**: Fully responsive across all device sizes
- **Component-Based Architecture**: Modular and reusable components
- **Type Safety**: Full TypeScript support for better developer experience
- **Fast Development**: Hot module replacement and fast refresh with Vite
- **Clean Code**: ESLint configured for code quality

## 📁 Project Structure

```
KOLAYA-DESIGN/
├── src/
│   ├── assets/          # Images, fonts, and static assets
│   ├── components/      # Reusable React components
│   ├── pages/          # Page components (Home, Services, About, Contact)
│   ├── styles/         # CSS/SCSS files
│   ├── App.css         # Main application styles
│   ├── App.tsx         # Root component
│   └── main.tsx        # Application entry point
├── public/              # Public assets
├── package.json         # Dependencies and scripts
└── vite.config.ts      # Vite configuration
```

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm/yarn/pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/navodlakshan/Kolaya-Design.git
   cd Kolaya-Design
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. Open your browser and navigate to `http://localhost:5173`
